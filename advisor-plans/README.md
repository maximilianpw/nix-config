  Fleet runtime without retaining migration-oracle ownership.

- **008 last among test changes** extracts the final registry after the legacy
  Fleet checks have been removed and the Rust consumer check renamed.

## Verification baseline

Use checks proportionate to each plan. The repository's standard gates are:

- Nix formatting: `alejandra --check <changed-nix-files>`
- Nix lint/pre-commit: `make lint`
- Evaluation: `nix flake check --no-build`
- Shell checks: `make check-scripts`
- One regression: `nix build .#checks.x86_64-linux.<name> --no-link`
- Host build without activation: `nix build .#nixosConfigurations.kim.config.system.build.toplevel --no-link`
- Documentation/diff hygiene: `git diff --check`

Building and evaluating are allowed. Do not run rebuild/switch, restore, backup migration, disk, deployment, cleanup, or live service commands unless explicitly requested.

## Findings considered and rejected or deferred

- **Delete broad homelab recovery tests** — rejected. Inventory validation, generated backup wiring, runtime failure recovery, archive inspection, and T3 Code snapshot behavior are separate safety layers, not redundant tests.
- **Split `lib/homelab-services.nix` because it is large** — rejected for now. It is intentionally the typed service/recovery inventory and size alone is not evidence of a bad boundary.
- **Generate `scripts/ynab-mcp-operations.json` reproducibly** — valid but deferred. It improves maintenance but is not part of the requested Nix folder/test/docs cleanup and needs upstream OpenAPI provenance decisions.
- **Rewrite `scripts/tests/t3code-post-activation-test.sh` as a behavioral harness** — valid but deferred. The current source-text test is brittle, but replacing it needs command-path injection and is not a deletion win.
- **Trim `docs/leerr.md` and move source provenance** — deferred. `packages/leerr.nix` explicitly depends on that document for provenance, and the doc contains active enrollment/recovery guidance. Address it only with a package-source ownership decision.
- **Delete `pkgs.cava` automatically** — rejected without user confirmation. The Waybar script is unused, but the CLI may still be used manually.
- **Archive deleted docs under another repo directory** — rejected. Git history already provides the archive; moving stale plans merely preserves active-doc clutter.
- **Change live systems while verifying cleanup** — rejected. All plans stop at evaluation/build checks unless the user separately authorizes activation.
